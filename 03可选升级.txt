默认 tesseract 识别出来的（错字很多）：
    主题: 关于配电箱与施工现场发生变化的事青
    1. 配电梢在招标工程量清单中均要求为正面双技|]，
    按照清单要求箱内有仪表、互感咽、塑壳断路怖等器件，
    各统一用双层| ]，无法在一个箱内合理安闭。
    2. 部分配电枯设计外形矿寸不符合箱内元怖件安效标准。

装了 RapidOCR 之后（几乎全对）：
    主题：关于配电箱与施工现场发生变化的事宜
    1.配电箱在招标工程量清单中均要求为正面双层门，
    按照清单要求箱内有仪表、互感器、塑壳断路器等器件，
    若统一用双层门，无法在一个箱内合理安装。
    2.部分配电箱设计外形尺寸不符合箱内元器件安装标准。

好消息：就算不装，检索也带错字容错。
用正确的词「断路器」「元器件」「合理安装」去搜，
系统也能命中扫描件里被认错的「断路怖」「元怖件」「合理安闭」。


──────────────────────────────
第一步：先看你这台机器的 Python 版本（决定能不能装）
──────────────────────────────

python3 -V

- 显示 Python 3.8.x  → 能装，继续下面
- 显示 3.9 / 3.10 / 3.11 / 3.12 等其他版本 → 包里的离线文件装不上，
  别硬装。把版本号告诉帮你做这个系统的人，换对应版本的包即可。

（原因：离线包里的二进制文件是按 Python 3.8 编译的，
其它 Python 版本加载会失败。这不是你的操作问题。）


──────────────────────────────
第二步：安装（照着敲，一条回车一下）
──────────────────────────────

1. 打开文件管理器，进到
   「考试检索系统 / RapidOCR离线包 / rapidocr_wheels」文件夹，
   在空白处右键 →「在终端打开」（终端会自动定位，不用敲 cd）

2. 输入：

python3 -m pip install --no-index --find-links=. rapidocr onnxruntime

   - 不需要联网
   - 看到 Successfully installed 就装好了

3. 验证：

python3 -c "from rapidocr import RapidOCR; RapidOCR(); print('RapidOCR 加载成功')"

看到 RapidOCR 加载成功 就是装好了。


──────────────────────────────
装完后怎么确认真的在用
──────────────────────────────

重启系统后，看两处：

1. 终端启动时，会打印一行「识别引擎:」
2. 打开网页，第二行会写「图文识别引擎：」

- 显示「RapidOCR　← 推荐」→ 装好了，正在用高准确率引擎
- 显示「tesseract 备用引擎　← ...」→ 没装上，仍在用备用引擎

这样不会糊里糊涂地一直用低准确率引擎还以为都一样。

如果装不上
──────────────────────────────
