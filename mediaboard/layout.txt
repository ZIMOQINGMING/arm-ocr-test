# 分屏布局 + 多节目页（仿 LEDvision 节目页/节目窗口）
# 每行一个窗口: 名称=起点X,起点Y,宽,高[,图片停留秒数][,窗口类型]
# 数字都是占屏幕的百分比（按整块屏幕算，左上角是 0,0）。
# 窗口类型: 文件(默认,图片视频轮播) / 文本 / 时钟 / 计时
#   也可不写类型，按名称自动识别：名称含「文本/通知」=文本窗，
#   含「时钟」=时钟窗，含「计时/倒计时」=计时窗。
# 「--- 秒数」单独一行 = 新建一个节目页，秒数=该页停留时间；页按顺序循环。
# 素材放 content/同名目录/ 里。
# 示例（去掉行首 # 启用）:
# 主画面=0,0,70,86
# 通知=70,0,30,28,10,文本
# 时钟=70,28,30,29,10,时钟
# 倒计时=70,57,30,29,10,计时
# --- 45
# 全屏海报=0,0,100,100,15
# 全部注释掉（默认）= 全屏轮播 content/ 顶层素材。
