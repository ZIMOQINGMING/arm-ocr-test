# 定时指令表（v4）——每行 HH:MM=指令，按本机时钟执行，同一分钟只执行一次
# 指令只做播放器内部动作，不碰系统（不重启、不关机，浏览器做不到）：
#   play:页码   跳到第 N 页（页码从 1 开始，按 layout.txt 里 --- 的先后）
#   pause       暂停自动换页（当前画面停住）
#   resume      恢复自动换页
#   screenoff   全屏黑（会议/清洁时用，省电防烧屏）
#   screenon    取消黑屏
#
# 示例（把行首 # 去掉即生效）：
# 08:00=play:1
# 08:30=resume
# 12:00=screenoff
# 13:30=screenon
# 18:00=play:2
